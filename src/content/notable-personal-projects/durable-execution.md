[durable-execution](https://github.com/gpahal/durable-execution) is a durable execution engine for running tasks and workflows resiliently, from a single function to a multi-step workflow. Tasks survive logic failures, process crashes and network errors, which makes it a good fit for AI workflows.

It's published to npm as five packages, with storage for Convex and Drizzle and [documentation](https://gpahal.github.io/durable-execution).
