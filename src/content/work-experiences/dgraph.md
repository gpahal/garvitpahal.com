Dgraph is an open-source distributed graph database with over 20,000 GitHub stars. It is built to be distributed and scalable.

I was a founding engineer at Dgraph. I launched Ratel, which is Dgraph's data visualisation and cluster management interface. I created tooling for the ecosystem. I built JavaScript (browser and Node.js) and Python clients for Dgraph and contributed to the other clients. I'm still the top contributor to Ratel and the JavaScript and Python clients. Those clients, with the JavaScript HTTP client for browsers, get about 100,000 downloads a month together. I also laid the groundwork for the Dgraph-as-a-service platform built on top of Kubernetes.
